# Security Policy

## Scope

SupplyChain Guardian AI is a defensive portfolio project. Its built-in package reputation, advisory, workflow, attestation, and incident data is synthetic. It does not fetch or execute dependency code, contact registries, publish artifacts, rotate secrets, or modify a release.

The fixture attestation checker validates declared demo fields; it is not a replacement for `gh attestation verify`, Sigstore verification, or an admission controller.

## Reporting

Please report suspected vulnerabilities privately through GitHub's security-advisory feature. Do not include real credentials, proprietary SBOMs, or customer data in a public issue.

## Supported version

The latest commit on `main` is the supported portfolio version.
